🏥 Doctor Appointment Management System

A modern full-stack Doctor Appointment web application where users can easily book appointments, manage schedules, and securely authenticate using Google login.

✨ Features
🔐 Google Authentication
👨‍⚕️ Doctor Appointment Booking
📅 Appointment Management
🧑 User Dashboard
🛡️ Protected Routes with JWT
🔄 Proxy API Integration
📱 Fully Responsive Design
⚡ Smooth Scrolling Experience
🎨 Modern UI with Tailwind CSS & Framer Motion
✏️ Users can update their profile information
🔄 Users can change appointment dates anytime
❌ Users can cancel appointments
🔍 View appointment details easily
💾 MongoDB Database Integration
📌 Clean and user-friendly interface

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone : https://github.com/dulal71/doctor-appointment-manager
Live link : https://doctor-appointment-manager-six.vercel.app/
2️⃣ Install Frontend
cd client
npm install

3️⃣ Install Backend
cd server
npm install

🔑 Environment Variables

🌐 Frontend .env.local
NEXT_PUBLIC_API_URL=your_api_url
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your_secret
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
⚙️ Backend .env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret


▶️ Run Project
🌐 Frontend

npm run dev
⚙️ Backend

nodemon index.js
